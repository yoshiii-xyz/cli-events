# Contributing

Keep changes within the protocol and reference-runner scope in
`docs/product-brief.md`. Do not add hosted services, frontend code, telemetry,
or compatibility claims that have not been tested.

Run the commands in `docs/release.md` for release changes. Review `git diff`
and the exact validation output before committing. Do not put credentials,
private keys, environment dumps, or secret values in source, fixtures, logs,
or QA evidence.
